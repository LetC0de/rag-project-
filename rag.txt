 ---
 Project Overview

 RAG Document Intelligence is a full-stack application that allows users to upload PDF documents and ask
 questions about their content using AI-powered retrieval and generation.

 Core Technology Stack

 - Backend: Flask (Python)
 - Frontend: Vanilla HTML/CSS/JavaScript
 - Vector Database: ChromaDB
 - AI/LLM: Mistral AI (embeddings + chat model)
 - Framework: LangChain
 - PDF Processing: PyPDF

 Key Components

 1. Backend API (backend/)

 Main Application (app.py):
 - Flask server with CORS enabled
 - Registers document and query blueprints
 - Health check endpoint
 - Max file size: 50MB

 Configuration (config.py):
 - Mistral API key management
 - Embedding model: mistral-embed-2312
 - LLM model: mistral-small-2506
 - Chunk size: 1000, overlap: 200
 - Retriever settings (MMR with k=4, fetch_k=10)

 Document Service (services/document_service.py):
 - PDF loading with PyPDFLoader
 - Text splitting into chunks
 - Vector embedding generation
 - ChromaDB collection management
 - Uses ChromaDB API for collection deletion (not file system)

 Query Service (services/query_service.py):
 - MMR (Maximal Marginal Relevance) retrieval
 - Context building from retrieved chunks
 - Prompt template for AI responses
 - Returns answer with source citations (page numbers)

 Vector Store Service (services/vectorstore_service.py):
 - ChromaDB initialization
 - Database existence checking
 - Collection name: "pdf_collection"

 API Endpoints:
 - GET /api/health - Health check + DB status
 - POST /api/documents/upload - Upload and process PDF
 - POST /api/query - Ask questions
 - DELETE /api/documents - Clear database

 ---
 RAG Pipeline Flow

 1. PDF Upload
    ↓
 2. PyPDFLoader extracts text
    ↓
 3. RecursiveCharacterTextSplitter creates chunks
    ↓
 4. MistralAIEmbeddings converts to vectors
    ↓
 5. ChromaDB stores vectors in collection
    ↓
 6. User asks question
    ↓
 7. MMR Retriever finds relevant chunks
    ↓
 8. Context + Question → Prompt Template
    ↓
 9. ChatMistralAI generates answer
    ↓
 10. Response with sources returned to UI
